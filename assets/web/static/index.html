What is WZR?
WZR is an AI-powered pipeline orchestrator for Sber infrastructure teams. It replaces ad-hoc manual release workflows with repeatable, shareable pipelines driven autonomously by Qwen Code CLI — with human approval gates, self-healing on failure, and live AI narration so you always know what's happening.
